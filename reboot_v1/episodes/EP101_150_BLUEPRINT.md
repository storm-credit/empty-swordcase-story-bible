# EP101~EP150 회차 설계

형식: `제목 — 핵심 사건 / 회차 보상 / 마지막 훅`

## ARC 6 — 무게와 천둥의 내전

- EP101 「산이 사람을 짓누른다」 — 철산국 진입과 동시에 중력이 뒤집혀 피난민들이 하늘 쪽 광벽으로 떨어진다. / 역중력 구조전. / 산심이 담운의 자루에 반응한다.
- EP102 「무게가 계급인 나라」 — 견딜 수 있는 하중으로 신분이 정해지는 철산국의 제도를 본다. / 권역 생활 소개. / 가장 무거운 왕관이 두 왕자 사이에서 갈라진다.
- EP103 「쌍왕자의 전쟁」 — 두 왕자가 산심을 깨워 왕위를 증명하려 한다. / 내전 목표 구체화. / 칠성문이 한 왕자의 편에 선다.
- EP104 「무겸의 사형을 죽인 칼」 — 무겸은 자신의 사형을 죽인 검흔이 칠성문 장로에게 있음을 확인한다. / 누명 축 재점화. / 장로가 무겸에게 복귀와 증거를 제안한다.
- EP105 「명예의 무게」 — 무겸은 증거를 얻기 위해 파티를 떠나는 척 칠성문 진영에 잠입한다. / 독립 행동. / 담운 일행이 반대편 왕자의 포로가 된다.
- EP106 「광부들의 하늘」 — 역중력 광구에서 광부들이 천장에 매달린 도시를 만든 모습을 본다. / 독특한 공간 보상. / 산심이 깨어나며 도시 전체가 중심으로 끌린다.
- EP107 「산을 멈추는 못」 — 담운은 잔흔과 빙갑검으로 붕괴를 임시 고정한다. / 기존 능력 조합. / 낯선 조사관 하진명이 사고 기록을 들고 나타난다.
- EP108 「조작된 생존자 명단」 — 하진명은 적화 사고에서 담운이 동료를 버렸다는 기록이 천율원에 의해 조작됐다고 밝힌다. / 과거 누명 일부 해소. / 기록 끝에 도각의 생존 표식이 있다.
- EP109 「스승은 살아 있다」 — 도각이 무명교의 지하 성역에 포로로 있다는 증거가 확인된다. / 개인 목표 대전환. / 권도혁이 하진명을 반역자로 지정한다.
- EP110 「산심을 깨우는 밤」 — 쌍왕자가 동시에 산심 의식을 시작하고 철산국 전체 중력이 무너진다. / 대규모 위기. / 무겸이 칠성문 군세를 이끌고 담운 앞에 선다.

- EP111 「배신자의 군세」 — 무겸은 배신한 듯 보이지만 군세의 진형을 뒤집어 피난로를 연다. / 무겸의 책략 보상. / 칠성문 장로가 천뢰고를 울린다.
- EP112 「죽은 병사들의 심장」 — 전쟁 북이 전사자들의 심박을 재생해 시체 군대를 일으킨다. / 뇌명극 기원 공개. / 담운의 심장이 북소리에 동조한다.
- EP113 「산의 심장을 드는 자」 — 담운은 산심을 차지하지 않고 무너지는 광구를 떠받치는 데 힘을 쓴다. / 천근도 획득 조건 달성. / 뼈가 금 가는 소리가 전신에서 난다.
- EP114 「천근도」 — 무게를 바꾸는 천근도로 산의 붕괴 방향을 돌린다. / 여섯 번째 검형 획득. / 장로가 천뢰고와 산심을 결합한다.
- EP115 「심장보다 빠른 적」 — 천뢰고를 두른 장로가 생각보다 먼저 움직이는 초고속 검술을 펼친다. / 뇌명극 전투 규칙 소개. / 무겸이 사형의 죽음 장면을 직접 본다.
- EP116 「증거를 태우는 검객」 — 무겸은 누명을 벗길 유일한 기록을 버리고 시체 군대를 멈추는 길을 택한다. / 인물 아크 전진. / 장로가 무겸의 사형 시신을 깨운다.
- EP117 「사형과의 마지막 합」 — 무겸은 시체가 된 사형과 정통 검술의 마지막 대결을 벌인다. / 감정·액션 절정. / 사형이 마지막 순간 북의 약점을 알려준다.
- EP118 「천둥을 삼키는 자루」 — 담운은 천뢰고 심축을 자루에 받아들이며 심장 손상을 감수한다. / 일곱 번째 본흔 접촉. / 몸이 생각보다 먼저 무겸을 공격한다.
- EP119 「내 몸이 휘두른 칼」 — 뇌명극의 폭주로 담운이 아군을 해칠 뻔하고 서린이 강제로 심박을 늦춘다. / 대가와 파티 신뢰 긴장. / 산 전체가 마지막으로 내려앉는다.
- EP120 「뇌명극」 — 천근도와 뇌명극의 첫 합흔으로 산을 고정하고 전쟁을 끝낸다. / 일곱 번째 검형 완성. / 권도혁이 도각과 서하를 넘기겠다는 거래를 제안한다.

## ARC 7 — 해문 아래의 선택

- EP121 「두 사람을 돌려주겠다」 — 권도혁은 도각과 서하의 신병을 조건으로 자루 양도를 요구한다. / 적대자의 합리적 제안. / 담운이 심장 손상과 잠식을 숨긴 사실을 서린이 알아낸다.
- EP122 「숨긴 대가」 — 서린은 진실을 숨긴 담운과 결별하고 독자적으로 서하를 찾으러 떠난다. / 파티 최대 분열 시작. / 해문군도에서 구조 신호가 온다.
- EP123 「하나만 구할 수 있다」 — 살아 있는 항구와 침몰 도시 중 하나만 조수 재앙에서 구할 수 있다는 계산이 제시된다. / 핵심 딜레마. / 침몰 도시가 배 아래에서 종을 울린다.
- EP124 「바다 밑의 주민들」 — 침몰 도시에도 살아남은 공동체가 존재함을 확인한다. / 희생 대상의 얼굴 부여. / 해군이 그들을 망령으로 규정한다.
- EP125 「조수 열쇠의 주인」 — 만상회와 해군이 각자 조수 열쇠를 차지해 한쪽 도시를 살리려 한다. / 세력 간 선택 대립. / 연비의 가족이 살아 있는 항구에 있다는 소식이 온다.
- EP126 「내 가족이 있는 쪽」 — 연비는 항구를 택하고 싶다고 솔직히 말해 파티와 충돌한다. / 조연 이해관계 현실화. / 침몰 도시 아이가 연비의 이름을 알고 있다.
- EP127 「바다가 기록한 빚」 — 과거 살아 있는 항구가 침몰 도시를 의도적으로 희생시켰다는 기록이 드러난다. / 지역 역사 반전. / 해류가 양쪽 도시를 동시에 집어삼키기 시작한다.
- EP128 「계산된 희생」 — 권도혁의 문서에는 한쪽을 포기하는 것이 피해 최소라고 적혀 있다. / 천율원 철학 재현. / 담운은 제3의 수로 가능성을 찾는다.
- EP129 「문이 열리는 시간」 — 공절검으로 해문 좌표를 읽지만 담운의 방향 기억이 급속히 무너진다. / 대가 누적. / 도각의 봉인 신호가 바다 밑에서 잡힌다.
- EP130 「바다 아래로 끌려가다」 — 침몰 도시 주민들이 파티의 배를 해문 밑으로 끌고 간다. / 수중 탐험 전환. / 파천검 자루가 담운의 척추에 뿌리를 내린다.

- EP131 「칼자루가 몸을 먹는다」 — 자루가 외부 도구가 아니라 담운을 새 칼날 재료로 바꾸고 있음을 확인한다. / 중대 반전 예고. / 담운은 이 사실을 남은 동료에게도 숨긴다.
- EP132 「침몰 도시의 재판」 — 침몰민들은 살아 있는 항구를 구하려면 자신들을 다시 희생시키라는 요구에 반발한다. / 정치·감정 사건. / 연비가 증언대에 선다.
- EP133 「빚을 갚지 않는 선택」 — 연비는 가족 때문에 항구를 택하고 싶었다고 인정하면서도 침몰민 희생에는 동의하지 않는다. / 연비 성장. / 만상회 선단이 해문을 폭파한다.
- EP134 「접힌 바다」 — 담운은 공절검으로 해류 공간을 접지만 풍아검과 충돌해 폭풍이 수중에서 발생한다. / 합흔 실패. / 청람이 계약을 끊겠다고 경고한다.
- EP135 「다시 소유하려 한 손」 — 담운은 급한 마음에 청람의 힘을 강제하려다 멈춘다. / 과거 오류의 실제 수정. / 청람이 스스로 새로운 항로를 보여준다.
- EP136 「세 번째 길」 — 파티와 두 도시 주민이 기존 두 수로가 아닌 폐쇄된 고대 배수로를 연다. / 제3의 선택 실행. / 열쇠를 지키는 해문수호자가 깨어난다.
- EP137 「물로 벤다」 — 담운은 흑염도·빙갑검을 이용해 수압과 온도 차를 조절하며 수호자와 싸운다. / 기존 검흔 재조합. / 조수 열쇠가 담운의 심장으로 들어온다.
- EP138 「두 도시의 문」 — 양쪽 주민이 동시에 문을 여는 조건을 충족해 조수 열쇠가 본흔을 내놓는다. / 공동 행동 보상. / 바다가 담운에게 수천 명의 익사 기억을 쏟는다.
- EP139 「해문월도」 — 담운은 해문월도로 해류를 절단·전환해 두 도시를 연결한다. / 여덟 번째 검형 획득. / 익사 기억 속에서 도각이 무명교 의식대에 묶여 있다.
- EP140 「등뼈가 된 칼자루」 — 해문 사건 뒤 자루와 담운의 척추가 완전히 연결된다. / 신체 침식 확정. / 황도에서 담운과 똑같은 영웅이 파천검을 바쳤다는 방송이 퍼진다.

## ARC 8 — 인연을 자르는 황도

- EP141 「내가 파천검을 바쳤다」 — 황도에 담운과 같은 얼굴의 국가 영웅이 나타나 자루를 천율원에 헌납했다고 선전한다. / 가짜 영웅 미스터리. / 진짜 담운의 지명수배가 해제된다.
- EP142 「존재하지 않는 범인」 — 지명수배가 사라진 대신 담운의 적화 사고 기록과 신분도 삭제된다. / 이름 삭제의 전조. / 여관 주인이 담운을 보지 못한다.
- EP143 「그림자를 훔치는 가면」 — 가짜 담운이 쌍면귀 가면으로 시민들의 기대와 기억을 훔친다는 사실을 안다. / 귀영쌍검 기원. / 연비의 그림자가 독립한다.
- EP144 「도둑보다 먼저 훔친 것」 — 연비의 그림자는 그녀가 숨긴 욕망, 즉 파티를 버리고 가족과 떠나고 싶다는 마음을 실행하려 한다. / 연비 내면 외부화. / 그림자가 자루를 가져간다.
- EP145 「가짜 영웅의 완벽한 선택」 — 국가 영웅은 항상 피해가 적은 정답만 골라 시민의 지지를 얻는다. / 담운과 대조되는 적. / 시민들이 진짜 담운을 사기꾼으로 몰아붙인다.
- EP146 「명성을 지킬 것인가」 — 담운은 자신의 공적을 증명할 자료를 얻지만 공개하면 파티의 비밀과 피해자도 노출된다. / 선택 갈등. / 서린이 독자적으로 조작 기록을 방송한다.
- EP147 「돌아온 기록사」 — 서린은 팀 복귀가 아니라 정보 동맹을 제안하며 가짜 영웅의 기록망을 해킹한다. / 관계 재구성. / 가짜 담운이 서하의 행방을 안다고 말한다.
- EP148 「영웅을 죽이면 진짜가 된다」 — 쌍면귀는 가짜를 죽이고 자리를 차지하라고 유혹한다. / 정체성 시험. / 담운의 그림자까지 분리된다.
- EP149 「내가 원했던 담운」 — 담운의 그림자는 두려움 없이 모두를 통제하는 이상적 자신으로 나타난다. / 내면 보스전. / 그림자가 도각을 먼저 구하러 간다.
- EP150 「귀영쌍검」 — 담운은 가짜 영웅과 자신을 함께 폭로하고 명성을 포기해 귀영쌍검을 얻는다. / 아홉 번째 검형 획득. / 독립한 그림자가 도각의 목에 칼을 댄다.
