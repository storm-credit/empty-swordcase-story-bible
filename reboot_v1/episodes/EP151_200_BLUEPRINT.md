# EP151~EP200 회차 설계

형식: `제목 — 핵심 사건 / 회차 보상 / 마지막 훅`

## ARC 8 — 인연을 자르는 황도

- EP151 「그림자가 간 곳」 — 담운의 독립 그림자가 도각을 죽이면 스승과의 약점이 사라진다고 주장한다. / 귀영쌍검의 위험 구체화. / 무명교가 그림자를 환영하며 성역 문을 연다.
- EP152 「끊으면 편해지는 관계」 — 연명사가 파티 앞에 나타나 가장 아픈 인연을 끊어 주겠다고 제안한다. / 명실검 시험 시작. / 무겸이 사형과의 기억을 끊으려 손을 뻗는다.
- EP153 「기억이 아니라 선택」 — 무겸은 고통스러운 기억을 남기고 파문 상태로 살아가기로 한다. / 무겸 아크 진전. / 연명사가 서린과 담운의 인연선을 끊는다.
- EP154 「서로를 모르는 동료」 — 담운과 서린은 기억은 남았지만 서로에게 느끼던 신뢰가 사라진 상태로 작전을 수행한다. / 관계의 기능 재시험. / 서린이 담운을 위험물로 봉인하려 한다.
- EP155 「명령하지 않는 동맹」 — 서린은 팀 복귀 조건으로 모든 중요 정보를 공유하고 자신의 거부권을 인정하라고 요구한다. / 파티 운영 재설계. / 담운은 자루 침식 사실을 전부 공개한다.
- EP156 「마지막 칼날은 나다」 — 파천검 자루가 열두 본흔을 통합할 때 사용자의 척추와 기억을 칼날로 바꾼다는 사실이 확정된다. / 중대 정본 반전. / 도각이 이를 알고 있었다는 기록이 나온다.
- EP157 「스승을 믿을 이유」 — 담운은 도각의 의도를 변명하지 않고 직접 묻기 위해 성역으로 향한다. / 목표 명료화. / 권도혁이 황도 봉쇄와 파티 체포를 시작한다.
- EP158 「관계를 자르는 칼」 — 연명사는 파티가 살려면 담운과의 인연을 모두 끊으라고 강요한다. / 최종 시험. / 청람이 스스로 계약선을 자른다.
- EP159 「떠날 권리」 — 청람은 관계를 끊는 것이 배신이 아니라 선택권의 증명이라고 보여준다. / 작품 주제 강화. / 담운이 강제 계약선만 보게 된다.
- EP160 「명실검」 — 담운은 사람 사이의 감정이 아니라 강제 맹약과 천율원의 통제선만 잘라 명실검을 얻는다. / 열 번째 검형 획득. / 무명교가 도각을 이용해 열두 본흔 소환 의식을 시작한다.

## ARC 9 — 죽은 자들이 원하는 검

- EP161 「지하 성역으로」 — 파티는 황도 아래 무명교 성역에 침투하고 수백 명의 이름 없는 신도들을 만난다. / 적대 집단의 인간적 면모. / 신도들이 담운을 `마지막 칼날`이라 부른다.
- EP162 「이름을 버린 사람들」 — 신도들은 천율원 기록에서 삭제된 뒤 무명교만이 자신들을 기억해 줬다고 말한다. / 무명교의 설득력. / 서하가 파티 앞에 나타난다.
- EP163 「서하의 미래」 — 서하는 천명망을 완전히 끊으면 수년 내 유물 재앙이 폭증한다고 예측한다. / 파천검 완성의 필요성 제시. / 서린은 언니와 떠날 기회를 얻는다.
- EP164 「언니를 찾은 뒤」 — 서린은 언니를 되찾는 것과 언니의 계획에 동의하는 것은 다르다고 선을 긋는다. / 서린 독립 아크 회수. / 도각의 비명과 함께 성역이 흔들린다.
- EP165 「깨진 나침반」 — 담운은 오랜 세월 봉인 장치에 묶인 도각과 재회한다. / 개인 목표 보상. / 도각이 담운에게 미안하다고 말하기 전에 자루가 폭주한다.
- EP166 「계산된 제자」 — 도각은 담운을 사랑해서가 아니라 기록되지 않은 생존자라 침식을 견딜 확률이 높아 선택했다고 고백한다. / 스승 배신감 정면화. / 담운이 도각을 떠나려 한다.
- EP167 「적화 사고의 진실」 — 사고 당시 담운은 동료를 버린 것이 아니라 도각의 명령으로 탈출로를 열었고, 천율원이 생존 기록을 조작했음이 밝혀진다. / 죄책감 사실 수정. / 죽은 동료들의 목소리가 성역에 울린다.
- EP168 「되살릴 수 있다」 — 반생화가 죽은 동료들을 되살릴 수 있다고 약속한다. / 부활 유혹 시작. / 담운 앞에 당시 동료가 살아 있는 모습으로 나타난다.
- EP169 「과거를 살리는 값」 — 부활에는 현재 파티원 한 명의 생명이 필요하다는 조건이 드러난다. / 선택 비용. / 심장 손상으로 담운이 쓰러지고 연비가 제물로 선택된다.
- EP170 「지금 살아 있는 사람」 — 담운은 과거 동료의 부활을 포기하고 연비를 구한다. / 내적 아크 큰 전환. / 반생화가 담운의 몸에 뿌리내린다.

- EP171 「상처를 나누는 칼」 — 반생화는 담운에게 파티의 상처를 대신 받을 능력을 보여준다. / 반생검 기능 예고. / 담운 몸에 모두의 상처가 동시에 나타난다.
- EP172 「도각의 마지막 계산」 — 도각은 자신이 죽으면 봉인이 유지된다고 판단해 희생하려 하지만 담운이 이를 거부한다. / 희생 클리셰 차단. / 무명대사가 봉인을 강제로 해제한다.
- EP173 「여러 사람의 목소리」 — 무명대사의 몸에서 연무진과 역대 계승자들의 목소리가 충돌한다. / 적대자 정체 완성. / 성역의 본흔 잔재들이 담운에게 몰려든다.
- EP174 「나 대신 아파하지 마라」 — 파티는 담운이 모든 상처를 혼자 짊어지는 것을 거부하고 각자 감당할 몫을 선택한다. / 관계 주제 회수. / 반생화가 칼 형상으로 변한다.
- EP175 「반생검」 — 담운은 상처를 저장·전이하는 반생검으로 의식 희생자들을 살리고 무명대사를 제압한다. / 열한 번째 검형 획득. / 천명망 마지막 기록판이 담운의 이름을 지우기 시작한다.
- EP176 「아무도 부르지 않는 이름」 — 성역 밖 사람들은 담운을 알아보지 못하고 기록에서도 그의 이름이 사라진다. / 무명검 대가 선행. / 무겸마저 담운에게 검을 겨눈다.
- EP177 「행동이 남긴 흔적」 — 무겸은 기억이 아니라 자신이 익힌 전투 합과 흉터를 통해 담운을 알아본다. / 관계의 물리적 회수. / 서린의 기록에서도 담운 이름이 빈칸이 된다.
- EP178 「이름 없는 스승과 제자」 — 도각은 담운 이름을 잊지만 몸이 먼저 옛 신호를 반복한다. / 스승 관계 감정 회수. / 서하가 마지막 기록판 위치를 밝힌다.
- EP179 「열한 자루의 행렬」 — 열한 본흔이 담운 주위에 독립 칼날로 떠오르며 황도를 향한다. / 최종부 시각 보상. / 좌현이 처음으로 모습을 드러낸다.
- EP180 「계산하는 불멸자」 — 좌현은 담운이 이름을 잃는 과정도 계획 일부였다고 말한다. / 최종 적 공개. / 모든 황도 시민의 선택이 한 문장으로 고정된다.

## ARC 10 — 파천검의 마지막 주인

- EP181 「선택이 사라진 아침」 — 황도 시민들이 같은 시간에 같은 행동을 반복하며 천명망 재가동이 시작된다. / 최종 재앙 체감. / 파티원 각자의 이름표가 바뀐다.
- EP182 「기억하지 못해도 찾는다」 — 서린은 기록 대신 사건의 인과를 따라 담운을 찾고, 연비는 갚지 않은 빚 목록으로 그를 확인한다. / 파티 관계 총회수. / 담운은 자신이 누구인지 말하지 못한다.
- EP183 「내 이름을 말하면 죽는다」 — 담운이 이름을 선언할 때마다 천명망이 존재를 더 깊이 삭제한다. / 무명검 시험 규칙. / 가짜 담운 영웅이 다시 나타난다.
- EP184 「마지막 가짜」 — 가짜 담운은 이름을 대신 가져가 주겠다고 제안하며 국가 영웅으로 남으려 한다. / 정체성 최종 대립. / 담운은 자신의 모든 공적 기록을 넘긴다.
- EP185 「공적 없는 사람」 — 담운은 영웅이라는 명성을 포기하고 평범한 무명인으로 천명망 안쪽에 들어간다. / 시험 진전. / 연무진이 자루를 완전히 장악한다.
- EP186 「연무진의 몸」 — 담운의 몸이 연무진의 검식을 펼치며 파티를 공격한다. / 내면·외면 동시 보스전. / 몽단검으로 두 기억을 분리할 기회가 한 번 열린다.
- EP187 「누구의 후회인가」 — 담운은 연무진도 처음에는 사람들을 구하려 했다는 기억을 보고 그를 단순 악으로 규정하지 않는다. / 최종 미스터리 인간화. / 연무진이 통제를 포기하지 못한 순간이 드러난다.
- EP188 「주인이라는 이름」 — 마지막 기록판은 파천검의 주인이 되겠다고 선언해야 힘을 준다. / 최종 유혹. / 담운은 주인 자격 자체를 버린다.
- EP189 「무명검」 — 자신의 이름과 주인 자격을 대가로 무명검을 얻어 천명망의 명령을 처음 지운다. / 열두 번째 검형 획득. / 열두 본흔이 하나의 파천검으로 합쳐지기 시작한다.
- EP190 「열두 자루, 한 사람」 — 완전한 파천검의 형상이 나타나고 담운의 몸이 칼날로 변하기 시작한다. / 최종 형태 공개. / 좌현이 가능한 모든 미래에서 파티의 죽음을 보여준다.

- EP191 「패배하는 모든 미래」 — 좌현은 담운이 어떤 검을 고르든 누군가 죽는 계산을 제시한다. / 최종 적 능력 체감. / 계산에 없는 빈칸 하나가 연비의 즉흥 행동으로 생긴다.
- EP192 「계산 밖의 사람들」 — 각 동료와 지역 세력이 중앙 지휘 없이 독립적으로 움직여 천명망 예측을 흔든다. / 200화 조연·지역 회수. / 권도혁이 천율원 인장을 파천검에 바친다.
- EP193 「질서를 위한 마지막 제안」 — 권도혁은 담운이 파천검의 영구 주인이 되면 전쟁과 재앙을 끝낼 수 있다고 설득한다. / 사상 최종 대립. / 무명대사도 모든 책임을 혼자 지라고 요구한다.
- EP194 「한 사람에게 맡기지 않는다」 — 담운은 자신도, 권도혁도, 무명대사도 천하의 선택을 독점할 수 없다고 선언한다. / 주제 명문화. / 좌현이 천명핵을 폭주시킨다.
- EP195 「파천검」 — 담운은 열두 본흔을 완전히 통합해 단 한 번의 파천검을 구현한다. / 제목급 절정 보상. / 파천검이 담운의 이름을 마지막으로 삼키려 한다.
- EP196 「하늘이 아니라 망을 벤다」 — 담운은 신이나 하늘이 아닌 천명망의 중심 연결을 벤다. / 세계 갈등 직접 해결. / 끊어진 힘이 대륙 전역으로 폭주한다.
- EP197 「마검의 마지막 주인」 — 연무진의 의지가 담운을 덮어 모든 힘을 자신에게 모으려 한다. / 최종 내면 대결. / 서린이 담운의 마지막 기억을 기록할지 지울지 선택한다.
- EP198 「기억을 돌려주지 않는다」 — 서린은 담운의 기억을 보존하는 대신 연무진과 분리하고, 파티는 본흔의 대가를 나눠 감당한다. / 동료 관계 절정. / 파천검이 열두 갈래로 갈라진다.
- EP199 「한 자루가 되지 않는 검」 — 담운은 본흔을 각 지역의 철회 가능한 수호 계약으로 분산하고 절대적 힘을 포기한다. / 세계·주제 결말. / 모든 검흔이 사라진 담운 손에 평범한 칼자루만 남는다.
- EP200 「다음 유적은 이름이 없다」 — 수개월 뒤 담운은 일부 기억과 명성을 잃었지만 살아 있으며, 동료들이 남긴 지도 조각을 들고 새 유적으로 향한다. / 완결과 모험의 여운. / 지도 끝 빈칸에서 아직 파천검과 무관한 새로운 유물의 종소리가 들린다.
