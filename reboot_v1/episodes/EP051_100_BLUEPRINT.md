# EP051~EP100 회차 설계

형식: `제목 — 핵심 사건 / 회차 보상 / 마지막 훅`

## ARC 3 — 접힌 사막의 지도

- EP051 「지도 안쪽의 도시」 — 담운 일행은 종이처럼 접힌 만리륜 내부에서 중력과 방향이 뒤집힌 거리를 통과한다. / 공절검의 공간 규칙 예고. / 도시의 중심에서 거대한 손이 지도를 다시 접는다.
- EP052 「길의 주인」 — 만상회 집행관은 길이 없는 사람은 존재하지 않는 것과 같다고 선언한다. / 적대 철학 구체화. / 주민들의 집이 좌표째 매각된다.
- EP053 「물 없는 탈출로」 — 연비는 고향 사람들을 빼내지만 물길이 접혀 모두 사막 한가운데 갇힌다. / 연비의 책임 강화. / 담운이 스승 도각의 비밀 좌표를 발견한다.
- EP054 「깨진 좌표」 — 도각이 접천도의 한쪽 귀퉁이에 파천검 본흔의 위치를 숨겼음을 안다. / 장기 단서 확보. / 좌표를 읽는 순간 담운의 과거 장소 기억 하나가 사라진다.
- EP055 「길을 잃는 대가」 — 공절의 잔광을 쓸수록 담운은 북쪽과 남쪽을 구분하지 못한다. / 대가 실전 적용. / 만상회가 사막 전체의 출구를 닫는다.
- EP056 「도시가 달린다」 — 만리륜의 바퀴를 다시 움직여 접힌 공간을 찢는 대규모 탈출전이 벌어진다. / 연비와 무겸의 조합 활약. / 도시가 절벽 끝으로 향한다.
- EP057 「가장 짧은 거리」 — 담운은 절벽과 반대편 오아시스 사이의 공간을 접어 구조로를 만든다. / 공절검 성형 직전 보상. / 접힌 틈 안에서 연무진의 전쟁 장면이 보인다.
- EP058 「모두의 지도」 — 주민들이 각자의 기억을 합쳐 접천도의 독점 좌표를 덮어쓴다. / 지역 문제 해결. / 접천도가 칼자루로 빨려 들어간다.
- EP059 「거리를 베는 공절검」 — 담운이 공절검을 완성해 만상회 집행관의 도주로를 잘라낸다. / 세 번째 검형 획득. / 담운은 도각의 얼굴이 떠오르지 않는다.
- EP060 「잃어버린 얼굴」 — 공절검의 대가로 스승의 얼굴 기억을 잃고, 연비가 파티에 정식 합류한다. / 감정 비용과 파티 강화. / 몽경도의 거울이 잃은 얼굴을 비춘다.

## ARC 4 — 기억을 먹는 섬

- EP061 「안개 속의 얼굴」 — 몽경도에 들어선 담운은 거울마다 서로 다른 도각의 얼굴을 본다. / 기억 미스터리 시작. / 서린의 언니 서하가 거울 속에서 손짓한다.
- EP062 「기억세」 — 주민들은 고통스러운 기억을 거울원에 맡기고 세금을 감면받는다. / 도시 생활과 유혹 소개. / 담운에게 적화 사고 기억을 맡기라는 제안이 온다.
- EP063 「편안해지는 값」 — 기억을 맡긴 사람들은 평온하지만 중요한 관계도 함께 잊는다. / 유물의 편익과 피해 동시 제시. / 무겸이 사형의 이름을 잊기 시작한다.
- EP064 「없는 언니」 — 모든 공식 기록과 주민 기억에서 서하가 존재하지 않는다. / 서린의 독립 목표 전진. / 서린 자신도 언니의 목소리를 잊는다.
- EP065 「내가 버린 사람들」 — 담운은 거울을 통해 자신이 적화 사고에서 동료들을 버리고 도망친 장면을 본다. / 죄책감 핵심 공개. / 다른 거울에서는 담운이 끝까지 남아 있는 장면이 나온다.
- EP066 「두 개의 과거」 — 파티는 서로 다른 적화 사고 기억을 갖게 된다. / 신뢰 균열. / 서린의 기억 속 담운이 사고를 일으킨다.
- EP067 「기억으로 만든 적」 — 거울원은 담운을 재앙의 원인으로 공개하고 주민들이 그를 추격한다. / 사회적 전투. / 연비가 담운을 모른다고 말한다.
- EP068 「낯선 동료들」 — 파티원들의 기억이 바뀌어 서로 적으로 인식한다. / 각 인물 음성과 기본 관계 재시험. / 무겸이 담운의 목을 겨눈다.
- EP069 「기억 없는 검술」 — 무겸과 담운은 서로를 몰라도 몸에 남은 합을 통해 협력한다. / 관계가 기억만으로 성립하지 않음을 증명. / 백몽경이 파티를 각자의 후회 속에 가둔다.
- EP070 「서린이 기억한 범인」 — 서린은 언니 실종과 적화 사고 모두 담운 때문이라고 확신한다. / 최대 감정 충돌. / 서린이 담운의 칼자루를 봉인한다.

- EP071 「후회를 버리는 방」 — 담운은 사고 기억을 완전히 지우면 거울 미궁을 나갈 수 있다는 제안을 받는다. / 유혹 구체화. / 지운 미래의 담운이 평온하게 웃는다.
- EP072 「남겨야 할 상처」 — 담운은 죄책감이 조작됐어도 자신이 내린 선택의 책임은 남기겠다고 한다. / 내적 성장. / 자루의 봉인이 스스로 풀린다.
- EP073 「거울 속 서하」 — 서하는 기록에서 지워진 뒤 무명교에 들어갔다고 말하며 서린에게 함께 오라 한다. / 서하 생존 확정. / 서하가 담운을 파천검의 마지막 칼날이라 부른다.
- EP074 「누구의 기억인가」 — 연무진의 기억이 담운의 과거 장면에 섞여 있음을 알아낸다. / 잠식 메커니즘 공개. / 담운이 자신도 모르게 연무진의 검식을 펼친다.
- EP075 「내 목소리로 말하는 자」 — 연무진이 담운의 입을 빌려 백몽경을 복종시키려 한다. / 내면 적대 첫 전면화. / 서린이 담운의 기억을 베어야 한다고 판단한다.
- EP076 「기억을 베는 사람」 — 서린은 봉인식으로 연무진과 담운의 기억 경계를 표시한다. / 서린의 전문성 보상. / 경계 안에 도각의 기억도 섞여 있다.
- EP077 「거울원의 진짜 세금」 — 맡겨진 기억이 천율원과 만상회에 팔려 시민 통제에 쓰였음이 드러난다. / 사회적 진실 회수. / 원로회가 도시 전체 기억을 초기화하려 한다.
- EP078 「백몽경의 심장」 — 담운은 자신의 가장 고통스러운 기억을 지우지 않고 거울의 중심까지 운반한다. / 몽단검 획득 조건 달성. / 거울이 담운에게 소중한 기억 하나를 요구한다.
- EP079 「환상을 끊는 몽단검」 — 담운은 스승의 목소리 기억 일부를 대가로 몽단검을 완성하고 도시 초기화를 막는다. / 네 번째 검형 획득. / 잃은 목소리로 연무진이 웃는다.
- EP080 「무명교의 예언자」 — 서린은 서하가 무명교의 예언자로 살아 있다는 좌표를 얻는다. / 다음 대목표 확정. / 풍수해의 신수들이 인간 항로를 전부 끊는다.

## ARC 5 — 폭풍의 계약

- EP081 「바다가 길을 닫았다」 — 풍수해의 모든 항로가 폭풍으로 막히고 식량선이 표류한다. / 해양 모험 시작. / 푸른 신수 청람이 배를 뒤엎는다.
- EP082 「신수를 사는 해군」 — 황실 해군은 청람에게 현상금을 걸고 뿔을 국가 유물로 지정한다. / 세력 갈등 소개. / 파천검 자루가 청람의 뿔에 반응한다.
- EP083 「사냥하지 않는 사냥꾼」 — 담운은 본흔을 얻을 기회에도 청람 사냥을 거부한다. / 주인공 원칙 형성. / 풍아족이 담운을 인간 사냥단의 첩자로 붙잡는다.
- EP084 「계절마다 끝나는 약속」 — 풍아족의 계약은 영구 소유가 아니라 계절마다 갱신된다는 전통을 배운다. / 세계관 보상. / 해군이 계약 문서를 위조해 신수를 징발한다.
- EP085 「바람이 기억한 배신」 — 청람의 감각을 통해 과거 인간들이 계약을 소유권으로 바꾼 장면을 본다. / 신수 관점 체험. / 청람이 담운에게 임시 감각을 건넨다.
- EP086 「두 눈으로 보는 폭풍」 — 담운은 청람의 시야와 자신의 몸을 동시에 제어하며 구조전을 벌인다. / 새로운 탐험·전투 감각. / 감각이 끊기지 않아 담운이 신수의 공포에 잠긴다.
- EP087 「뿔이 부러진 날」 — 청람의 뿔은 인간에게 빼앗긴 것이 아니라 계약자를 구하려 스스로 부러뜨린 것임이 밝혀진다. / 풍아검 기원 갱신. / 사냥단이 부러진 뿔을 탈취한다.
- EP088 「폭풍 경매」 — 만상회가 사냥단과 해군을 모아 뿔의 공개 경매를 연다. / 잠입·경제 갈등. / 연비가 경매 참가자로 담운을 판다.
- EP089 「사람보다 비싼 항로」 — 경매 참가자들은 신수보다 항로 독점권을 노린다. / 적의 실제 욕망 공개. / 폭풍이 경매장을 공중으로 들어 올린다.
- EP090 「동의 없는 힘」 — 파티가 추락하자 담운은 청람의 동의 없이 자루로 풍아검을 강제 호출한다. / 불완전 풍아검 첫 사용. / 청람이 계약을 끊고 담운을 폭풍 속에 버린다.

- EP091 「떠난 신수」 — 풍아검이 사라지고 파티는 무동력선으로 폭풍 안에 갇힌다. / 힘 상실 긴장. / 청람이 해군의 쇠사슬 감옥에 잡힌다.
- EP092 「칼 없이 건너는 하늘」 — 담운은 공절검과 돛 조작만으로 상승기류를 건넌다. / 기존 검흔 창의적 재사용. / 뇌우 속에서 심장이 불규칙하게 뛴다.
- EP093 「계약을 어긴 대가」 — 풍아족은 담운을 추방하고 청람 구출을 돕지 않는다. / 관계 대가 현실화. / 서린이 청람의 감각 잔향에서 구조 좌표를 찾는다.
- EP094 「폭풍 감옥」 — 해군은 청람의 날개와 뿔을 항로 엔진에 연결한다. / 잔혹한 유물 활용 공개. / 담운은 풍아검을 쓰지 않겠다고 선언한다.
- EP095 「신수보다 느린 사람」 — 담운은 인간의 몸으로 공중 쇠사슬을 하나씩 끊는다. / 주인공의 비능력적 헌신. / 해군 제독이 폭풍 엔진을 폭주시킨다.
- EP096 「돌아오지 않아도 된다」 — 담운은 청람에게 계약 복귀를 요구하지 않고 도망갈 길만 연다. / 비소유 관계 완성. / 청람이 혼자 떠난다.
- EP097 「바람이 돌아온 이유」 — 청람은 풍아족 아이들을 구하기 위해 자발적으로 돌아온다. / 신수의 독립 행동. / 부러진 뿔이 자루 앞에 놓인다.
- EP098 「다시 쓰는 계약」 — 인간과 신수가 철회권을 가진 새 항로 계약을 맺는다. / 지역 문제 해결. / 청람이 담운과 조건부 재계약한다.
- EP099 「폭풍을 두르는 풍아검」 — 풍아검이 완성되고 담운은 해군의 폭풍 엔진을 해체한다. / 다섯 번째 검형 획득. / 풍아검의 바람 속에서 철산국의 전쟁 북소리가 들린다.
- EP100 「계약은 칼보다 오래간다」 — 청람은 파티에 소속되지 않고 동행을 선택한다. / Act 3 전반 결산. / 천율원·칠성문·철산국이 본흔을 두고 전쟁을 시작한다.
