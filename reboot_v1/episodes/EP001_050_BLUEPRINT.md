# EP001~EP050 회차 설계

형식: `제목 — 핵심 사건 / 회차 보상 / 마지막 훅`

## ARC 1 — 적화분지의 흑염

- EP001 「버려진 길잡이」 — 담운은 적화 폐광 탐사대의 후퇴로를 찾다가 동료들에게 미끼로 버려진다. / 폐광의 역방향 지도를 확보한다. / 닫힌 석문 안에서 칼날 없는 자루가 울린다.
- EP002 「불이 차갑다」 — 광산 화재인데도 사람들의 체온과 등불이 꺼지는 이상 현상을 파악한다. / 화귀가 불이 아니라 열을 먹는다는 규칙을 발견한다. / 얼어붙은 불꽃 속에서 생존자의 손이 나온다.
- EP003 「고철 한 자루」 — 담운은 자루를 챙기고 갇힌 광부들을 구하려 하지만 칼날은 나타나지 않는다. / 자루가 유물의 방향을 가리킨다는 기능이 열린다. / 심장 박동이 광산 전체에서 들린다.
- EP004 「화귀의 심장」 — 광산 중심에서 거대한 불귀와 심장을 발견한다. / 화귀가 채굴단의 열 추출 실험으로 태어났음을 안다. / 탐사대장이 심장을 팔기 위해 돌아온다.
- EP005 「살아남은 자의 값」 — 탐사대장은 광부들을 버리고 심장만 가져가자고 제안한다. / 담운이 퇴로 대신 구조로를 선택한다. / 석문이 닫히며 산소가 끊긴다.
- EP006 「금서 기록사」 — 서린이 봉인을 깨고 들어와 담운을 도굴범으로 오해한다. / 화귀 문양과 파천마검록의 첫 문장이 공개된다. / 천율원 봉쇄대가 광산 입구를 폭파한다.
- EP007 「불을 빼앗긴 광부들」 — 담운과 서린은 광부촌이 수년간 체온을 유물에 빼앗겨 왔음을 확인한다. / 피해자와 유물의 연결선이 보인다. / 화귀가 마을 쪽으로 이동한다.
- EP008 「칼날 없는 싸움」 — 담운은 검 없이 함정과 광차로 화귀의 움직임을 막는다. / 길잡이 기술이 전투 자산으로 증명된다. / 자루에 검은 금이 한 줄 생긴다.
- EP009 「심장을 잡는 손」 — 담운은 타오르는 심장을 맨손으로 붙잡고 광부들의 열을 되돌린다. / 첫 검흔의 이름 `흑염`을 듣는다. / 담운의 팔에서 체온이 사라진다.
- EP010 「흑염의 잔광」 — 불완전한 흑염도가 순간 구현되어 화재를 삼킨다. / 첫 전투 보상과 능력 공개. / 구천하 곳곳의 금단유물이 동시에 울린다.

- EP011 「국가급 도굴범」 — 천율원은 사고 책임을 담운에게 씌우고 체포령을 내린다. / 적화 사건 공식 기록의 모순을 확보한다. / 서린이 담운의 이름이 과거 사고 기록에도 있음을 발견한다.
- EP012 「열을 파는 상회」 — 만상회가 광부촌의 열을 담보로 채굴권을 샀다는 계약이 드러난다. / 백사문의 첫 등장. / 상회가 화귀 심장의 소유권을 주장한다.
- EP013 「도망치지 않는 길」 — 담운은 빠져나갈 수 있지만 마을 방벽 복구를 택한다. / 주민들의 임시 협력망을 얻는다. / 흑염도가 담운의 감정까지 먹기 시작한다.
- EP014 「차가운 분노」 — 담운은 동료를 해친 탐사대장을 보면서도 분노를 느끼지 못한다. / 검흔 대가가 구체화된다. / 탐사대장이 화귀의 잔핵을 삼킨다.
- EP015 「사람이 된 화귀」 — 잔핵에 잠식된 탐사대장과 광산 추격전이 벌어진다. / 흑염도의 흡수 한계를 시험한다. / 검은 불이 지하 화맥으로 번진다.
- EP016 「꺼지지 않는 폐광」 — 담운은 화맥을 끊으면 분지 전체가 얼어붙는다는 사실을 안다. / 단순 파괴가 정답이 아님을 확인한다. / 서린이 도각의 표식을 발견한다.
- EP017 「깨진 나침반의 글씨」 — 스승 도각이 남긴 경로와 `북쪽의 얼어붙은 명령`이라는 문장을 읽는다. / 장기 목표가 생긴다. / 화귀가 담운에게 자신의 기억을 보여준다.
- EP018 「불의 마지막 주인」 — 화귀가 수백 명의 열과 원망이 뭉친 존재임을 알고 심장을 완전히 받아들인다. / 흑염도 성형 조건 달성. / 담운의 심장 박동이 화귀와 겹친다.
- EP019 「불을 먹는 흑염도」 — 담운은 흑염도로 지하 폭주를 흡수해 검은 화염으로 배출한다. / 첫 완전 검형 획득. / 흡수한 불길 속에서 낯선 남자가 담운의 이름을 부른다.
- EP020 「파천마검의 목소리」 — 연무진의 잔존 의지가 처음으로 말을 걸고 자루가 두 번째 본흔을 가리킨다. / 파천검 미스터리 시작. / 권도혁이 담운을 직접 회수하라는 명령을 내린다.

## ARC 2 — 설왕의 얼음 명령

- EP021 「눈이 멈추지 않는 나라」 — 담운 일행은 설관령에 들어서자 같은 눈송이가 반복해서 떨어지는 현상을 겪는다. / 설관령의 법칙 소개. / 얼음 병사가 담운에게 무릎을 꿇는다.
- EP022 「두 번째 왕」 — 얼음 병사들이 담운을 왕으로 부르며 주민 징집 명령을 요구한다. / 자루와 설왕 갑주의 공명 확인. / 무겸이 담운을 마검 사용자로 공격한다.
- EP023 「정통검과 고철자루」 — 무겸과 담운이 좁은 설교에서 맞붙는다. / 정통 검술과 변칙 전투 대비. / 전투 소리가 얼음 회랑에서 명령으로 증폭된다.
- EP024 「말하면 죽는다」 — 모든 말이 군령으로 변하는 회랑에서 파티는 무언으로 이동한다. / 손짓·공간 전투 보상. / 서린의 기침 한 번에 얼음 병사들이 자결을 시작한다.
- EP025 「명령을 취소하는 법」 — 기존 명령은 더 강한 명령으로만 덮을 수 있다는 규칙을 파훼한다. / 서린의 봉인 능력 활약. / 섭정단이 왕의 목소리를 재현한다.
- EP026 「죽은 왕의 목소리」 — 설왕이 죽기 전 남긴 마지막 명령이 백성을 영원히 보호하라는 것이었음을 안다. / 재앙의 선의 기원. / 보호 명령이 모든 주민을 성 안에 가둔다.
- EP027 「얼음 성의 탈출자」 — 주민들이 스스로 성을 나가려 하자 병사들과 충돌한다. / 지역 주민이 행동 주체가 된다. / 무겸의 사형 살해 증거가 왕실 창고에서 발견된다.
- EP028 「명예의 증거」 — 무겸은 누명을 벗을 증거를 얻을 기회와 주민 구조 사이에서 흔들린다. / 무겸의 내적 갈등 전진. / 칠성문 원정대가 증거를 먼저 회수한다.
- EP029 「얼어붙은 선택」 — 담운이 흑염도로 성벽을 녹이면 도시가 눈사태에 묻힌다는 사실을 안다. / 능력 상성의 한계. / 설왕 갑주가 새 숙주를 찾는다.
- EP030 「갑주가 고른 왕」 — 갑주가 담운의 몸에 달라붙으며 모든 병사를 지휘할 권한을 준다. / 두 번째 본흔 접촉. / 담운이 무겸에게 자신을 베라고 명령한다.

- EP031 「왕이 되면 끝난다」 — 갑주를 입으면 즉시 재앙을 끝낼 수 있지만 담운의 선택권도 사라진다. / 권력 유혹을 구체화한다. / 주민들이 담운에게 왕이 되어 달라고 요청한다.
- EP032 「명령 없는 방벽」 — 담운은 주민들에게 명령하지 않고 각자가 맡을 방벽을 제안한다. / 자율 협력의 첫 성공. / 섭정단이 식량 창고를 얼린다.
- EP033 「차가운 칼의 대가」 — 갑주의 방어 본질을 잠시 사용하며 담운의 통각이 사라진다. / 빙갑검 잔광. / 담운이 자신의 부러진 손가락을 알아채지 못한다.
- EP034 「느끼지 못하는 상처」 — 통각 없이 싸우던 담운이 치명상을 키운다. / 대가가 전투 판단에 영향. / 무겸이 담운을 업고 적진에 남는다.
- EP035 「사형의 마지막 검」 — 무겸은 사형이 칠성문의 본흔 쟁탈을 막다 죽었다는 진실을 본다. / 무겸 누명 축 해소. / 칠성문 장로가 설왕 갑주를 강탈한다.
- EP036 「칠성문의 왕」 — 장로가 갑주를 입고 얼음 병사들을 문파 군대로 바꾼다. / 인간 적대자가 재앙을 악용. / 갑주가 담운에게 장로를 죽이라고 속삭인다.
- EP037 「명령을 베지 않는다」 — 담운은 장로가 아니라 갑주와 명령선 사이를 흑염도로 녹인다. / 비살상적 검흔 응용. / 얼음 병사들이 명령 없이 멈춰 선다.
- EP038 「왕이 없는 나라」 — 주민들은 새 왕을 세우지 않고 임시 의회를 구성한다. / 지역 결말 보상. / 갑주가 빈 채 담운 앞에 무릎을 꿇는다.
- EP039 「빙갑검」 — 담운이 명령 기능을 거부하고 방어와 동결만 받아들여 빙갑검을 완성한다. / 두 번째 검형 획득. / 연무진이 `명령 없는 힘은 오래가지 않는다`고 말한다.
- EP040 「국가급 재앙」 — 무겸이 파티에 합류하고 권도혁이 담운을 국가급 유물 재앙으로 공표한다. / 파티 강화와 대륙 추격 시작. / 접경사막의 도시 하나가 지도에서 사라진다.

## ARC 3 — 접힌 사막의 지도

- EP041 「지도에서 사라진 도시」 — 일행은 만리륜의 좌표가 모든 지도에서 지워진 사실을 확인한다. / 새 지역 미스터리. / 모래 속에서 도시의 바퀴 소리가 들린다.
- EP042 「길을 파는 사람들」 — 만상회가 물길과 안전로를 시간 단위로 판매한다. / 사막 경제와 갈등 소개. / 연비가 담운의 칼자루를 훔친다.
- EP043 「칼자루 없는 사냥꾼」 — 담운은 검흔 없이 길 함정과 추격자를 상대한다. / 주인공 기본 능력 재증명. / 연비가 자루를 쥐자 모든 길이 그녀를 피해 접힌다.
- EP044 「길이 거부한 도둑」 — 연비는 자루를 팔지 못하고 담운에게 조건부 거래를 제안한다. / 연비의 고향 목표 공개. / 만리륜이 사막 절벽 안으로 접혀 들어간다.
- EP045 「바퀴 도시 만리륜」 — 파티는 움직이는 거대 도시의 바퀴축으로 잠입한다. / 이동도시 생활 보상. / 도시 주민들이 자신들이 지도에서 지워진 줄 모른다.
- EP046 「하루가 반복되는 길」 — 접천도가 주민의 이동 기억까지 접어 같은 하루를 반복시킨다. / 시간처럼 보이는 공간 현상 파훼. / 서린이 도각의 오래된 거래 기록을 찾는다.
- EP047 「스승이 산 지도」 — 도각이 파천검 본흔 위치를 숨기기 위해 접천도를 구매했다는 흔적이 나온다. / 스승의 비밀 확대. / 연비가 만상회와 밀약하는 장면을 담운이 본다.
- EP048 「배신의 가격」 — 연비는 담운의 위치를 넘기는 대가로 고향 주민의 좌표를 되돌려 달라 한다. / 실제 이해관계 충돌. / 담운이 만상회 감옥으로 접혀 이동된다.
- EP049 「접힌 감옥」 — 출구가 매 순간 다른 벽에 나타나는 감옥에서 담운은 발자국과 모래 흐름을 읽는다. / 칼 없이 공간 퍼즐 해결. / 감옥 밖에서 연비가 경비를 전부 잠근다.
- EP050 「도둑의 진짜 길」 — 연비의 밀약이 주민 탈출 시간을 벌기 위한 계획이었음이 드러난다. / 불완전 신뢰 형성. / 접천도가 도시 전체를 지도 안쪽으로 삼킨다.
