# EP111~EP120 집필 압축 패킷 v3.4

> 보호 정본의 집필용 요약이다. 목표·선택·보상·훅·비용을 변경하지 않는다.

## EP111 되풀이되는 침몰
- Act/Subact: ACT3 / ACT3-SA4 (공동 소유와 수장의 얼굴)
- 장소: 침몰도시 중앙창고·무명시 지하역로
- 등장: 진여강, 담운, 서린화, 소예란, 두리
- 목표: 기억 닻 때문에 과거 폭풍과 배신이 재현된다.
- 선택: 진여강이 자신의 증서를 버릴지 고민
- 보상: 파도 기억 공개
- 비용: 과거 폭풍을 재현해 부유역참 두 곳이 파손되고 일행이 배상 책임을 진다.
- 훅: 과거 침몰 원인이 소유권 독점이었다.
- 기능: 새 문제와 지역 규칙 도입
- 장면 비트:
  1. hook_recovery — 직전 화의 훅을 침몰도시 중앙창고·무명시 지하역로에서 즉시 행동 문제로 회수한다. / 행동: 진여강·담운가 직전 훅의 물리적 결과를 확인하고 이번 목표를 선택한다. / 변화: 이번 화의 즉시 목표와 실패 손실이 고정된다.
  2. world_pressure — 지역 운영 규칙과 생활 병목이 목표를 제한하는 방식을 장면화한다. / 행동: 침몰도시 중앙창고·무명시 지하역로의 검문·거래·수선·운송·생계 중 현재 비용과 직접 맞닿은 행동을 수행한다. / 변화: 시간·돈·장비·권리·관계 중 최소 하나가 악화된다.
  3. first_attempt — 기억 닻 때문에 과거 폭풍과 배신이 재현된다. / 행동: 진여강·담운가 가장 직접적인 해결 시도를 실행한다. / 변화: 초기 해법이 불완전하다는 사실과 반대자의 정당성이 드러난다.
  4. evidence_and_counterpressure — 문서 설명보다 생활 흔적·사용 기록·관계 반응을 먼저 확인한다. / 행동: 후보 참조(CI067:first)를 소유 보상이 아니라 증거·제약·책임으로 사용한다. / 변화: 첫 해석이 수정되고 비가역 선택의 기준이 생긴다.
  5. irreversible_choice — 진여강이 자신의 증서를 버릴지 고민 / 행동: 담운 또는 핵심 동료가 하나의 이익·권한·전력·관계를 실제로 포기한다. / 변화: 비용이 즉시 지불되고 이전 상태로 돌아갈 수 없게 된다.
  6. reward_cost_and_next_hook — 파도 기억 공개 / 행동: 보상·정보·관계 변화가 실제 행동이나 물건 상태로 확인된다. / 변화: 다음 화의 첫 행동을 발생시키는 물리·관계·권리 잔여가 남는다.
