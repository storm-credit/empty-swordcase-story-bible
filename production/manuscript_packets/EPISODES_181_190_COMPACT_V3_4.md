# EP181~EP190 집필 압축 패킷 v3.4

> 보호 정본의 집필용 요약이다. 목표·선택·보상·훅·비용을 변경하지 않는다.

## EP181 회수 대상 담운
- Act/Subact: ACT5 / ACT5-SA3 (중앙 소유권 전쟁)
- 장소: 중앙핵 내부·육도 분산 전장
- 등장: 담운, 백장, 서린화, 소예란, 두리, 곽무석
- 목표: 백장이 봉인 완성을 위해 담운을 확보한다.
- 선택: 동료들이 담운의 선택권을 지키려 함
- 보상: 강제 봉인 장치
- 비용: 일부러 붙잡혀 반치와 검함을 백장에게 압수당한다.
- 훅: 담운이 일부러 백장에게 잡힌다.
- 기능: 새 문제와 지역 규칙 도입
- 6비트: hook_recovery → world_pressure → first_attempt → evidence_and_counterpressure → irreversible_choice → reward_cost_and_next_hook
