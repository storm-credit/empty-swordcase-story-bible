# EP021~EP030 집필 압축 패킷 v3.4

> 보호 정본의 집필용 요약이다. 목표·선택·보상·훅·비용을 변경하지 않는다.

## EP021 만 가지 보물의 시장
- Act/Subact: ACT1 / ACT1-SA3 (진품보다 오래 살아남은 가짜)
- 장소: 경도 만보시장·시민 전시관
- 등장: 담운, 서린화, 진여강
- 목표: 담운 일행이 경도 만보시장과 유물 거래 규칙을 익힌다.
- 선택: 담운이 가격표에 압도됨
- 보상: 시장 도감 개방
- 비용: 시간·안전·관계 중 최소 하나를 실제 대가로 지불한다.
- 훅: 한숨풀무의 경매 번호가 갑자기 말소된다.
- 기능: 새 문제와 지역 규칙 도입
- 6비트: hook_recovery → world_pressure → first_attempt → evidence_and_counterpressure → irreversible_choice → reward_cost_and_next_hook
