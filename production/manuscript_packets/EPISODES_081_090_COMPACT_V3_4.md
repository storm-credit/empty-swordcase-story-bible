# EP081~EP090 집필 압축 패킷 v3.4

> 보호 정본의 집필용 요약이다. 목표·선택·보상·훅·비용을 변경하지 않는다.

## EP081 사막으로 열린 문
- Act/Subact: ACT3 / ACT3-SA1 (사막문과 상극의 전시실)
- 장소: 서황막 대상로·천공무고 폐분관
- 등장: 담운, 서린화, 소예란, 두리, 곽무석
- 목표: 눈 위 문을 통과해 서황막 대상 한복판에 떨어진다.
- 선택: 일행이 귀장회 추적에서 잠시 벗어남
- 보상: 사막문 기록
- 비용: 사막문이 닫히며 북설로 즉시 돌아갈 길과 구조 요청 수단을 잃는다.
- 훅: 뒤돌아본 문이 사라진다.
- 기능: 새 문제와 지역 규칙 도입
- 6비트: hook_recovery → world_pressure → first_attempt → evidence_and_counterpressure → irreversible_choice → reward_cost_and_next_hook
