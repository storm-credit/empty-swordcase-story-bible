# EP191~EP200 집필 압축 패킷 v3.4

> 보호 정본의 집필용 요약이다. 목표·선택·보상·훅·비용을 변경하지 않는다.

## EP191 소유권을 자르는 칼
- Act/Subact: ACT5 / ACT5-SA4 (소유권을 자르는 칼과 마지막 배송)
- 장소: 붕괴하는 원형 무고·최종 배송로
- 등장: 담운, 서린화, 소예란, 두리, 곽무석, 진여강
- 목표: 담운이 귀로식 반치로 자신의 이름과 중앙핵 사이 선을 자른다.
- 선택: 자기 소멸 대신 강제 관계를 끊음
- 보상: 귀로식 5식 완성
- 비용: 자기 이름 선을 자르며 담운은 과거 수장 권한과 어린 시절 일부 기억을 잃는다.
- 훅: 이름 선 뒤에 수천 개의 다른 선이 드러난다.
- 기능: 새 문제와 지역 규칙 도입
- 6비트: hook_recovery → world_pressure → first_attempt → evidence_and_counterpressure → irreversible_choice → reward_cost_and_next_hook
