# EP151~EP160 집필 압축 패킷 v3.4

> 보호 정본의 집필용 요약이다. 목표·선택·보상·훅·비용을 변경하지 않는다.

## EP151 곽무석의 완성 방패
- Act/Subact: ACT4 / ACT4-SA4 (동료들의 완성과 마지막 빈칸)
- 장소: 육도 열쇠 집결지·천외문
- 등장: 곽무석, 백장, 담운, 서린화, 소예란, 두리
- 목표: 무석이 팔 복원 대신 방패의 이름 해방을 선택한다.
- 선택: 무석 개인 아크 완결
- 보상: 무석 완성 방패
- 비용: 무석은 팔 복원 가능성을 영구히 포기하고 방패를 공동 방어 전용으로 바꾼다.
- 훅: 방패가 백장의 공격을 한 번 되돌린다.
- 기능: 새 문제와 지역 규칙 도입
- 6비트: hook_recovery → world_pressure → first_attempt → evidence_and_counterpressure → irreversible_choice → reward_cost_and_next_hook
