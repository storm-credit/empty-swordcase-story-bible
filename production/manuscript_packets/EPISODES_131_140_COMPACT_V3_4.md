# EP131~EP140 집필 압축 패킷 v3.4

> 보호 정본의 집필용 요약이다. 목표·선택·보상·훅·비용을 변경하지 않는다.

## EP131 무명시의 이름장부
- Act/Subact: ACT4 / ACT4-SA2 (중앙 장부를 해체하다)
- 장소: 무명시 중앙 장부실·시민광장
- 등장: 담운, 서린화, 소예란, 두리, 곽무석
- 목표: 도시 모든 이름과 소유권이 중앙 장부에 묶여 있다.
- 선택: 담운이 무주함과 같은 중앙화 구조를 인식
- 보상: 이름장부 발견
- 비용: 이름 가격을 확인한 담운은 무명시에서 거래·숙박을 할 법적 인격을 잃는다.
- 훅: 장부 마지막 줄에 자신의 이름 가격이 적혀 있다.
- 기능: 새 문제와 지역 규칙 도입
- 6비트: hook_recovery → world_pressure → first_attempt → evidence_and_counterpressure → irreversible_choice → reward_cost_and_next_hook
