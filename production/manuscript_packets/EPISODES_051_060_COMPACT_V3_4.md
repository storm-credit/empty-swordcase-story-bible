# EP051~EP060 집필 압축 패킷 v3.4

> 보호 정본의 집필용 요약이다. 목표·선택·보상·훅·비용을 변경하지 않는다.

## EP051 그리움의 냄새
- Act/Subact: ACT2 / ACT2-SA2 (잠든 숲을 놓아주다)
- 장소: 잠든 숲·천공무고 신수 분류실
- 등장: 담운, 두리, 소예란, 서린화, 허잠
- 목표: 두리의 능력으로 사라진 신수와 사람의 흔적을 구분해 추적한다.
- 선택: 담운과 예란 협업 시작
- 보상: 두리 능력 1단계
- 비용: 추적 중 두리의 냄새 감각이 과열돼 한 시진 동안 담운도 구별하지 못한다.
- 훅: 냄새가 향로가 아니라 마을 원로에게 이어진다.
- 기능: 새 문제와 지역 규칙 도입
- 6비트: hook_recovery → world_pressure → first_attempt → evidence_and_counterpressure → irreversible_choice → reward_cost_and_next_hook
