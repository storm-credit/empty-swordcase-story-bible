# EP101~EP110 집필 압축 패킷 v3.4

> 보호 정본의 집필용 요약이다. 목표·선택·보상·훅·비용을 변경하지 않는다.

## EP101 바다 위의 역참
- Act/Subact: ACT3 / ACT3-SA3 (침몰도시의 여섯 주인)
- 장소: 동해 부유역참·침몰도시 외곽
- 등장: 담운, 서린화, 소예란, 두리, 곽무석
- 목표: 섬과 섬 사이를 잇는 부유 역참에서 통행 규칙을 배운다.
- 선택: 담운이 바다 길에 적응
- 보상: 동해 조수표
- 비용: 부유역참의 조수 지연으로 미래 숨빚 상환일까지 쓸 수 있는 시간이 하루 줄어든다.
- 훅: 역참 장부에 같은 물건의 주인이 여섯 명 적혀 있다.
- 기능: 새 문제와 지역 규칙 도입
- 6비트: hook_recovery → world_pressure → first_attempt → evidence_and_counterpressure → irreversible_choice → reward_cost_and_next_hook
