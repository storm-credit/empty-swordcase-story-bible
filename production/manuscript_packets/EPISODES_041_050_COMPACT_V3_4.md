# EP041~EP050 집필 압축 패킷 v3.4

> 보호 정본의 집필용 요약이다. 목표·선택·보상·훅·비용을 변경하지 않는다.

## EP041 마지막 풍비
- Act/Subact: ACT2 / ACT2-SA1 (계약을 거부한 신수)
- 장소: 남독택 독안개 마을·야생계약소
- 등장: 담운, 두리, 서린화, 소예란
- 목표: 두리가 바람을 먹고 수레 천막을 날려 버린다.
- 선택: 담운이 생명과 물건을 같은 방식으로 다루면 안 됨을 체감
- 보상: 풍비 생태 공개
- 비용: 수레 천막과 약재 두 상자가 젖어 남독 통행 검사 순번을 반나절 뒤로 미룬다.
- 훅: 두리가 남독택 방향으로 울부짖는다.
- 기능: 새 문제와 지역 규칙 도입
- 6비트: hook_recovery → world_pressure → first_attempt → evidence_and_counterpressure → irreversible_choice → reward_cost_and_next_hook
