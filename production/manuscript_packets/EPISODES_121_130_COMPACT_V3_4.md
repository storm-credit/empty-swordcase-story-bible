# EP121~EP130 집필 압축 패킷 v3.4

> 보호 정본의 집필용 요약이다. 목표·선택·보상·훅·비용을 변경하지 않는다.

## EP121 이름을 파는 도시
- Act/Subact: ACT4 / ACT4-SA1 (이름을 잃은 담운)
- 장소: 무명시 이름시장·하층 골목
- 등장: 담운, 서린화, 소예란, 두리, 곽무석
- 목표: 무명시에서는 이름, 호칭, 죄명까지 거래된다.
- 선택: 담운이 이름 없는 상태의 편리함과 공포를 봄
- 보상: 이름 거래 규칙
- 비용: 통행을 위해 임시 이름을 사며 담운의 본명 사용권이 하루 정지된다.
- 훅: 상인이 담운의 이름은 이미 팔렸다고 말한다.
- 기능: 새 문제와 지역 규칙 도입
- 장면 비트:
  1. hook_recovery — 직전 화의 훅을 무명시 이름시장·하층 골목에서 즉시 행동 문제로 회수한다. / 행동: 담운·서린화가 직전 훅의 물리적 결과를 확인하고 이번 목표를 선택한다. / 변화: 이번 화의 즉시 목표와 실패 손실이 고정된다.
  2. world_pressure — 지역 운영 규칙과 생활 병목이 목표를 제한하는 방식을 장면화한다. / 행동: 무명시 이름시장·하층 골목의 검문·거래·수선·운송·생계 중 현재 비용과 직접 맞닿은 행동을 수행한다. / 변화: 시간·돈·장비·권리·관계 중 최소 하나가 악화된다.
  3. first_attempt — 무명시에서는 이름, 호칭, 죄명까지 거래된다. / 행동: 담운·서린화가 가장 직접적인 해결 시도를 실행한다. / 변화: 초기 해법이 불완전하다는 사실과 반대자의 정당성이 드러난다.
  4. evidence_and_counterpressure — 문서 설명보다 생활 흔적·사용 기록·관계 반응을 먼저 확인한다. / 행동: 후보 참조(CI073:first)를 소유 보상이 아니라 증거·제약·책임으로 사용한다. / 변화: 첫 해석이 수정되고 비가역 선택의 기준이 생긴다.
  5. irreversible_choice — 담운이 이름 없는 상태의 편리함과 공포를 봄 / 행동: 담운 또는 핵심 동료가 하나의 이익·권한·전력·관계를 실제로 포기한다. / 변화: 비용이 즉시 지불되고 이전 상태로 돌아갈 수 없게 된다.
  6. reward_cost_and_next_hook — 이름 거래 규칙 / 행동: 보상·정보·관계 변화가 실제 행동이나 물건 상태로 확인된다. / 변화: 다음 화의 첫 행동을 발생시키는 물리·관계·권리 잔여가 남는다.
