# EP141~EP150 집필 압축 패킷 v3.4

> 보호 정본의 집필용 요약이다. 목표·선택·보상·훅·비용을 변경하지 않는다.

## EP141 보물 지도가 퍼졌다
- Act/Subact: ACT4 / ACT4-SA3 (여섯 갈래 수집 전쟁)
- 장소: 육도천하 분산 전장
- 등장: 담운, 서린화, 소예란, 두리, 곽무석, 진여강
- 목표: 누군가 육도 천품 위치를 공개해 문파·상단·귀장회가 움직인다.
- 선택: 일행이 전쟁을 막기 위해 분산
- 보상: 육도 공개지도
- 비용: 지도 공개로 청래역을 포함한 민간 거점이 약탈 위험에 노출된다.
- 훅: 지도 발신지가 천외산맥이다.
- 기능: 새 문제와 지역 규칙 도입
- 6비트: hook_recovery → world_pressure → first_attempt → evidence_and_counterpressure → irreversible_choice → reward_cost_and_next_hook
