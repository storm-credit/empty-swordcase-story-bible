# EP161~EP170 집필 압축 패킷 v3.4

> 보호 정본의 집필용 요약이다. 목표·선택·보상·훅·비용을 변경하지 않는다.

## EP161 천외산맥을 오르다
- Act/Subact: ACT5 / ACT5-SA1 (살아 있는 박물관)
- 장소: 천외산맥·원형 천공무고
- 등장: 담운, 서린화, 소예란, 두리, 곽무석, 진여강
- 목표: 중력이 뒤집히는 계단과 분류 문을 통과한다.
- 선택: 담운이 동료 도움 없이는 전진 불가
- 보상: 천외 길표
- 비용: 뒤집힌 계단에서 장비 상자 하나가 추락해 보조 수집품 세 점을 잃는다.
- 훅: 문이 각자에게 다른 소유자 질문을 던진다.
- 기능: 새 문제와 지역 규칙 도입
- 6비트: hook_recovery → world_pressure → first_attempt → evidence_and_counterpressure → irreversible_choice → reward_cost_and_next_hook

## EP162 주인 없는 문
- Act/Subact: ACT5 / ACT5-SA1 (살아 있는 박물관)
- 장소: 천외산맥·원형 천공무고

- 목표: 누구도 소유하지 않은 문은 통과자를 스스로 선택한다.
- 선택: 담운이 무주가 공백이 아닌 선택 상태임을 이해
- 보상: 무주문 기록
- 비용: 무주문이 선택할 때까지 기다리느라 백장이 다른 경로로 먼저 진입한다.
- 훅: 문이 백장도 통과시킨다.
- 기능: 규칙의 예외와 비용 확대
- 6비트: hook_recovery → world_pressure → first_attempt → evidence_and_counterpressure → irreversible_choice → reward_cost_and_next_hook
