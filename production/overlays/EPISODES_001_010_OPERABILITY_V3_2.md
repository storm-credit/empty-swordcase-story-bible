# EPISODES 001–010 OPERABILITY OVERLAY v3.2

> 목적: 기존 사건을 바꾸지 않고 생활·직업·이동·감정 압력을 장면 인과로 전환한다.

## EP001
- 현재 목표: 검함의 정식 수신인 확인
- 지역 생활 압력: 청래역 창고와 인수 창구의 과밀
- 직업·물류 압력: 검함 보관으로 다른 짐을 받지 못해 하루 수입 감소
- 담운의 자발적 목표: 의뢰서 밖의 실제 수신 경로 확인
- 감정 압박: 절차 지연으로 손해 본 상인이 담운을 원망
- 이동 전/후: 평판·돈 변동
- 갈등 후 세계 변화: 인수 확인 절차 강화
- 감각 표식: 젖은 목재 냄새, 수레바퀴 마찰음, 진흙 바닥
- 설명 행동화: 청래역 규칙 설명을 인수 거부 장면으로 전환
- 기존 사건 변경: 없음

## EP002
- 현재 목표: 반치의 현재 책임자와 사용 조건 확인
- 지역 생활 압력: 수선 순번과 작업 도구 부족
- 직업·물류 압력: 결함 있는 반치가 이동과 작업을 방해
- 담운의 자발적 목표: 소유권 분쟁의 실제 손실 조사
- 감정 압박: 반치를 빼앗기면 생계가 무너지는 피해자 구체화
- 이동 전/후: 엄지 상처·돈·철구 신뢰 중 둘 이상 변동
- 갈등 후 세계 변화: 도구 인수·사용 기록 방식 변경
- 감각 표식: 쇳가루 냄새, 풀무의 저음, 손잡이의 닳은 감촉
- 설명 행동화: 반치 설정 설명을 수선 실패로 전환
- 기존 사건 변경: 없음

## EP003 「첫 번째 수집」
- 현재 목표: 반치와 공동 풀무의 책임 관계 확정
- 지역 생활 압력: 공동 풀무를 유지하는 노동과 연료 분담
- 직업·물류 압력: 반치를 가져가면 대장간 또는 주민이 실제 손해
- 담운의 자발적 목표: 의뢰받지 않은 유지 노동의 책임자 찾기
- 감정 압박: 올바른 선택 때문에 누군가의 작업 순번 상실
- 이동 전/후: 장비 획득 대신 빚·평판·관계 증가
- 갈등 후 세계 변화: 공동 제작 규칙과 비용 분담 변경
- 감각 표식: 숯 냄새, 망치 박자, 뜨거운 돌바닥
- 설명 행동화: 풀무 제도를 연료 부족과 작업 중단으로 전환
- 기존 사건 변경: 없음
