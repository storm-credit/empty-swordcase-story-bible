## 작품 핵심

> 유적에서 주운 칼날 없는 자루가 기이한 유물을 삼킬 때마다 새로운 칼을 만든다. 담운은 열두 본흔을 모을수록 강해지지만, 마지막 칼이 완성되는 순간 파천마검의 칼날이 되어 사라진다.

## EP001~EP020 완료 요약

### EP001~EP005 — 폐광과 화귀의 심장
담운은 탐사대의 미끼로 버려지지만 역방향 지도를 남기고 부상자들을 구한다. 차가운 불이 열을 먹는다는 규칙과 칼날 없는 자루의 방향 감지 기능을 발견한다. 광산 중심의 거대한 화귀 심장과 만상회 열 추출 실험이 드러난다.

### EP006~EP010 — 금서 기록사와 첫 잔광
서린이 등장해 파천마검록의 첫 문장을 공개한다. 광부촌 주민들의 생체열이 계약으로 추출됐다는 진실이 밝혀지고, 담운은 화귀를 지형과 함정으로 상대한다. EP009에서 `흑염` 이름을 듣고 EP010에서 불완전한 흑염도 잔광을 처음 구현한다.

### EP011~EP015 — 국가급 수배와 사람 화귀
천율원은 담운을 국가급 도굴범으로 지정한다. 백사문은 치료약과 신분을 조건으로 자루를 요구하지만 담운은 거절한다. 주민들은 만상회 중앙 열관 대신 세 화맥을 직접 복구한다. 탐사대장 오진백은 잔핵에 잠식되어 사람 형태 화귀가 된다.

### EP016~EP020 — 완전한 흑염도와 연무진
담운은 화맥 전체를 끊는 해법을 거부하고 검은 불을 우회 배출한다. 스승 도각의 표식과 설관령 경로를 찾고, 희생자들의 이름과 원망을 받아들여 흑염도 성형 조건을 충족한다. EP019에서 완전한 흑염도를 얻고, EP020에서 최초 사용자 `연무진`의 잔존 의지가 처음 말을 건다. 권도혁은 담운과 자루의 직접 회수를 명령한다.

## 활성 연속성

- 흑염도: 불과 열 흡수·검은 화염 방출
- 대가: 담운의 체온과 감정의 온기 소모
- 오른팔 저체온과 감각 손실 지속
- 도각과 뜨거운 국물을 먹던 기억의 감정 상실
- 연무진과 대화 시 미세한 체온 소모
- 서린과의 안전 규칙: 감정 둔화 시 되돌릴 수 없는 선택 단독 확정 금지
- 국가급 수배와 권도혁의 직접 추적
- 다음 방향: 북쪽 설관령과 두 번째 본흔
