# 《빈 검함으로 천하를 수집한다》 Story Bible

무협 판타지 웹소설의 세계관·설정집·장편 설계 저장소입니다.

## 핵심 콘셉트

청래역의 배달부 담운은 주인이 지워진 빈 검함을 맡는다. 검함은 무주 상태가 된 유산을 보관할 수 있지만, 강탈품과 살아 있는 신수는 소유할 수 없다. 담운은 천하의 보물과 실패한 고수들의 흔적을 수집하면서, 결국 ‘무엇을 가질 수 있는가’보다 ‘누구에게 돌려주어야 하는가’를 결정하는 귀로인이 된다.
