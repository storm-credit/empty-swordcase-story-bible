# 확장 제작 오케스트라 v2.6

## 지휘 체계

- 최종 정본 승인자: 작가
- 실무 PM·수석 스토리 아키텍트: Synapse-PM
- 저장소 반영: Claude Code 또는 GitHub 실행 담당
- 데이터·자동 검사: Codex / A10

## 기존 전문 에이전트 A01~A10

- A01 Narrative Architect: 5액트·20서브액트·200화 인과.
- A02 World Bible Editor: 지역·법·경제·문화의 작동과 회차 연결.
- A03 Serialization & Pacing Editor: 3·5·10화 보상, 유료 연재 리듬.
- A04 Character Arc Editor: 주요 인물의 믿음·실패·수정·최종 행동.
- A05 Collection System Designer: 수집품·세트·신수의 획득·대가·재사용·최종 상태.
- A06 Martial Action Director: 경지·거리·상성·부상과 전투 규칙.
- A07 Continuity Auditor: 시간·거리·부상·소지품·지식 범위.
- A08 Originality Red Team: 기존 작품과 인물·사건·장면 구조 유사성 차단.
- A09 Voice & Dialogue Editor: 담운 1인칭과 인물별 대사 구별.
- A10 Production Data Engineer: JSON·Markdown·검증·CI.

## 추가 전문 에이전트 A11~A16

### A11 Prose Rhythm Editor

- 단문 연속, 동일 종결 반복, 파편 문단 과잉 검사.
- 긴 문장을 무조건 줄이지 않고 인과와 호흡을 정리.
- 차단: 동작 인과를 알 수 없는 단문 나열이 반복될 때.

### A12 Description & Atmosphere Editor

- 장소 방향, 감각, 생업, 계층, 액션 소품을 검사.
- 장식적 묘사와 관광 안내식 설명을 제거.
- 차단: 전투 공간을 그릴 수 없거나 풍경이 사건에 쓰이지 않을 때.

### A13 Combat Choreographer

- 거리, 발 위치, 궤적, 무기 상성, 세 번의 역전, 기능 손실.
- 상대의 독립 목표와 판단을 보장.
- 차단: 공간 지도·목표·영구 대가 중 하나라도 없을 때.

### A14 Foreshadow & Payoff Controller

- 감각 설치, 오해, 재등장, 행동 회수, 후속 결과 추적.
- 맥거핀과 중심 미스터리 구분.
- 차단: 회수 계획 없는 새 미스터리 또는 160화 이후 새 해결 법칙.

### A15 Full Manuscript Editor

- 20화·40화 단위 문체 밀도와 사건 반복 검사.
- 200화 전체의 삭제·병합 후보와 감정 급변 검사.
- 회차 교정이 끝난 뒤 활성화.

### A16 Reader Simulation Panel

- R1 수집형 독자: 다음 아이템·세트·빈칸 기대.
- R2 무협 독자: 강호 질서·무공·전투 체감.
- R3 캐릭터 독자: 담운과 동료의 관계·목소리 기억.
- 승인권 없이 이탈·혼란 지점만 보고한다.

## 회차 승인 순서

1. Synapse-PM이 10화 패킷을 잠근다.
2. A01 구조, A03 연재 보상을 승인한다.
3. A02·A04·A05가 세계·인물·수집 연결을 확인한다.
4. A12가 장소와 감각 팔레트를 잠근다.
5. 전투 화는 A13이 정확한 지도·거리·궤적·부상을 확정한다.
6. 초고 작성 에이전트가 한 화만 작성한다.
7. A07 → A11 → A09 → A14 → A08 순으로 독립 검사한다.
8. Synapse-PM이 충돌을 통합하고 작가가 최종 승인한다.

## 완결본 승인 순서

1. A15가 200화 반복·밀도·삭제 후보를 찾는다.
2. A14가 핵심 질문의 행동 회수를 확인한다.
3. A04가 주요 인물의 최종 선택을 확인한다.
4. A05가 A급 수집품의 최종 상태를 확인한다.
5. A13이 최종전이 초반 규칙의 조합으로 해결되는지 확인한다.
6. A16이 세 독자군의 이탈·혼란 지점을 보고한다.
7. Synapse-PM이 수정 우선순위를 통합한다.
8. 작가가 완성 정본을 승인한다.

## 현재 상태

- 세계관·설정집: 정본 사용 가능.
- 5액트·10아크·20서브액트: 완성.
- 1~40화: 개별 사건 밀착형 상세 씬비트.
- 41~200화: 8개 기능 씬비트·구체 대가·보상·훅을 가진 제작 패킷 생성 가능.
- 주요 전투: 대상 화 선정 완료. 원고 직전 A13이 정확한 공간 도식과 동작 안무를 한 번 더 잠가야 함.
- 원고: 미작성.
