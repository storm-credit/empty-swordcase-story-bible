## 3. 정본 권한

`data/collection_system_governance_v3_3.json`이 세 후보 파일보다 우선한다.

현재 권한은 다음과 같다.

- 파일 구조와 수량: 자동 검증 가능
- 기존 확정 요소: 보호 정본
- 자동 생성 신규 이름: provisional
- 원고에서 확정 사용: 금지
- 공식 정본 승격: 작가 승인 필요

따라서 “120·24·18이 작성됐다”와 “120·24·18이 작가 승인 정본이다”를 구분한다.

## 5. 발견된 국소 교정

`SET002 청래 귀환 세트`의 원시 후보 데이터에는 완성 화가 10화로 적혔으나 구성품 `CI007·CI008`이 11~12화에 처음 등장한다.

거버넌스 오버레이에서 유효 완성 화를 **20화**로 교정했다. 원시 후보를 바로 정본으로 사용하지 않고 거버넌스와 검증기를 거치는 이유다.
