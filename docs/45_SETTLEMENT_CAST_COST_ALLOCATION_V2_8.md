# 45. 거점·조연·대가 배정 정본 v2.8

> 목적: 세계관 설정이 백과에만 머물지 않도록 48개 거점, 반복 조연 28명, 회차별 실제 대가를 1~200화 제작 데이터에 직접 연결한다.

## 1. 완료 판정

- 48개 거점 모두 본편 회차에 최소 2회 연결.
- 조연 28명 모두 첫 등장과 예정 재등장·종착 회차에 연결.
- 1~200화 모든 회차에 서로 다른 구체 대가를 기록.
- 장소명은 `world_settlements_048.json`의 정본 이름만 사용.
- 141~160화 분산 전쟁은 기존 지역 거점 재방문으로 구성하고 새 임시 지명을 남발하지 않음.

## 4. 회차별 대가 원칙

- 모든 회차의 대가는 부상, 감각 손실, 장비 기능 제한, 시간 손실, 권리 포기, 관계 변화, 제도적 책임 중 최소 하나를 구체적으로 명시한다.
- `시간·안전·관계 중 하나` 같은 선택형 자리표시자는 금지한다.
- 같은 대가 문장을 두 회차에 재사용하지 않는다.
- 대가는 다음 화의 행동 선택에 영향을 주어야 하며, 회차 말미에 지불한 뒤 다음 화에서 사라지면 안 된다.
- 전투 부상은 피의 양보다 손가락 감각, 발목 회전, 호흡, 시야, 장비 교체 시간 같은 기능 손실로 기록한다.
