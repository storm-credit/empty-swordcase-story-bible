## 2. 추가한 작동성 필드

`data/character_emotional_operability_overlay_v3_3.json`

각 인물은 다음을 가진다.

- 담운과 무관한 사적 목표
- 숨기는 열등감·죄책감·두려움
- 도움이나 협력을 거절할 선
- 담운의 선택 때문에 입는 사적 손실
- 담운이 없을 때 스스로 내리는 선택
- 담운 및 다른 인물과의 관계 압력
- 감정선이 집중되는 회차

이는 인물이 소유권·봉인·가격·계약 같은 주제의 입장만 말하는 기능 인물로 굳는 문제를 막기 위한 것이다.

## 3. 정본 보호

- 이름·직업·기존 음성·기존 생존·이탈은 변경하지 않는다.
- 후보 감정선이 기존 사건과 충돌하면 후보만 수정한다.
- 자동 생성된 사적 과거와 감정 세부는 작가 승인 전 원고에 확정 설정처럼 사용하지 않는다.
- 담운이 없어도 선택할 수 있게 하되, 기존 주연의 핵심 변화선을 빼앗지 않는다.

## 4. 발견한 충돌과 교정

기존 인물 `청묘`는 부유계단 정비사다. 신수 후보 레지스트리의 `BS015`에도 같은 이름이 들어가 사람·신수 고유명 충돌이 발생했다.

`data/collection_system_governance_v3_3.json`에서 BS015의 유효 후보명을 `빈매듭물범`으로 교정했다. 기존 인물명이 우선한다.

## 5. 검증

```bash
python scripts/validate_character_operability_v3_3.py
```

검사 항목:

- 음성 카드 원본 28명과 정확한 수량·이름·순서 일치
- CH001~CH028 연속 ID
- 신규 인물 혼입 금지
- 사적 목표·열등감·거절선·개인 손실·담운 부재 선택·관계 압력 존재
- 집중 회차 범위와 중복 검사
- 사람과 신수의 유효 이름 충돌 검사
- 작가 승인 전 provisional 유지

## 6. 남은 감사

1. 각 `focus_episodes`가 실제 등장 회차·캐스트와 일치하는지 확인
2. 서로 다른 인물이 같은 감정 기능을 반복하지 않는지 비교
3. 감정선이 5액트 전환과 기존 이탈·생존 결과를 바꾸지 않는지 확인
4. 작가 승인 또는 국소 교체

## 7. 현재 판정

> **기존 28명의 음성과 구조는 보존됐고, 감정·관계 작동성 전수 후보가 추가됐다. 신규 사적 과거와 세부 감정은 자동 검증 및 작가 승인 전까지 공식 정본이 아니다.**
