# 작문 하네스 복선·회수 보충 규칙 v2.7

## 역할 분리

- `docs/41_PROSE_STYLE_AND_WEBNOVEL_BIBLE.md`: 문장·시점·풍경·전투·대화·회차 리듬.
- `production/continuity/PAYOFF_ARCHITECTURE_V2_7.md`: 장편 질문, 서브액트 추적축, 인물·수집품 회수 일정.
- `data/episode_payoff_index_001_200.json`: 각 화에서 활성화할 정확한 S/A/CH/IT 원천 ID.
- `scripts/build_episode_payoff_tags_v2_7.py`: 감각 단서·오해·행동 회수·잔여 변화가 포함된 전체 태그 생성.
- 10화 작업 패킷: 어떤 장면에서 어떤 태그를 사용할지 배치.
- 원고: 태그명을 노출하지 않고 행동·물성·오해·선택으로 구현.

## 회차 필수 입력

- `new_question_id`: 새 장기 질문. 없을 수 있으며 최대 1개.
- `revisit_ids`: 기존 S/A/CH/IT 추적축.
- `minor_payoff_id`: 첫 10%에서 갚을 직전 화 훅.
- `sensory_seed`: 설명 없이 보이는 냄새·흠집·소리·반응.
- `current_false_answer`: 당시 정보로 가장 합리적인 오해.
- `action_payoff`: 정답 때문에 누가 무엇을 실제로 포기하거나 바꾸는가.
- `residual_change`: 회수 후 남는 관계·제도·장비·부상 상태.

## 문장 구현 규칙

- “훗날 중요한 단서였다”라고 예고하지 않는다.
- 같은 복선은 냄새 → 흠집 → 문서 오류 → 회피 행동처럼 매체를 바꾼다.
- 담운·린화·진여강·예란은 같은 단서를 서로 다른 직업 언어로 해석한다.
- 오해는 당시 정보로 가장 합리적인 답이어야 한다.
- 정답 발표 전에 행동을 쓴다.
- 회수 직전 장문의 회상을 금지하고 핵심 감각 이미지 한두 개만 되살린다.
- 회수 직후 새로운 미스터리를 덮어씌우지 않고 최소 한 장면 후속 변화를 보여준다.
- 결말 회수는 힘의 상승보다 누가 권한을 내려놓고 어떤 책임을 나누는지로 판정한다.

## 10화 단위 권장 밀도

- A-Tier 추적축 1개.
- S-Tier 재등장 1~2개.
- 인물 변화 진행 1개 이상.
- 핵심 수집품의 기능·대가·재사용 중 2개 이상.
- 소형 질문 3~5개를 분산한다.
- 9화 행동 클라이맥스, 10화 후속 변화와 다음 추적축 개방.

## 금지

- 모든 물건을 장기 복선으로 만들기.
- 끝 훅을 매번 정체 공개나 배신으로 처리하기.
- 맥거핀 획득으로 갈등이 자동 종료되는 구조.
- 결말에서 초반 물건 이름만 언급하고 회수했다고 처리하기.
- 의미 없는 표식·예언·꿈으로 복선 수를 부풀리기.
