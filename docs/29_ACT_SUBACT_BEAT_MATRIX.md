# 29. Act/Subact Beat Matrix v3.1

> 원천 데이터: `data/acts_subacts_005_020.json`, `data/episode_payoff_index_001_200.json`, `data/episode_payoff_tags_001_200.json`

## 10화 리듬

1. 새 문제와 지역 규칙.
2. 상대의 정당성과 비용 확대.
3. 첫 적용과 오판.
4. 적대 압박 구체화.
5. 중간 선택.
6. 선택의 후폭풍.
7. 숨은 진실 또는 역전.
8. 해결책 조립과 대가 확정.
9. 클라이맥스.
10. 보상, 상태 변화, 다음 질문.

## 검수 원칙

- 각 Subact는 이전 Subact의 선택 비용에서 시작한다.
- 10화마다 A-Tier 추적축 1개와 S-Tier 재등장 1개 이상이 있어야 한다.
- 끝 훅은 다음 화 첫 10%에서 행동으로 회수한다.
- 결말부 160화 이후 새 S-Tier 해결 법칙을 만들지 않는다.

## 사용법

작업자는 이 문서로 리듬을 확인하고, 실제 회차별 태그와 장면 입력은 JSON 원천을 읽는다.
