# 41. Prose Style and Webnovel Bible v3.1

> 이 문서는 경로 호환용 요약본이다. 전체 작문 하네스 원천은 `docs/WRITING_HARNESS_V2_5.md`와 `docs/WRITING_HARNESS_PAYOFF_ADDENDUM_V2_7.md`다.

## 핵심 원칙

- 담운 1인칭 중심으로 쓴다.
- 파편 단문의 연속을 금지한다.
- 풍경은 방향, 생활, 위험, 감정, 액션 준비 중 최소 두 기능을 해야 한다.
- 전투는 거리, 발 위치, 궤적, 재질, 기능 손실을 추적 가능하게 쓴다.
- 대사는 정보 전달보다 이해관계 충돌을 먼저 가진다.
- 설정 설명은 담운이 현재 선택하는 데 필요한 만큼만 노출한다.
- 첫 10%는 직전 훅을 행동으로 회수한다.
- 마지막 20%는 선택의 대가와 다음 행동 훅을 남긴다.

## v3.1 추가

Arcadium/Yota 비교 후, 지역 생활과 경제가 장면 안에서 사건을 만들도록 다음을 추가 적용한다.

- 해당 권역의 주식, 이동 병목, 생활 금기, 감각 표식 확인.
- 해당 세력의 독점 자원, 고정비, 내부 파벌 확인.
- 문서·계약 해결만 반복하지 않고 몸, 돈, 관계, 물류 손실 중 하나를 장면 대가로 사용.
- 생활 사물은 복선이 아니어도 닳고, 빌려지고, 돌아오며 세계를 지속시킨다.
